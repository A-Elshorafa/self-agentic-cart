# Cart App — Built by Claude Code Sub-Agents

A single-page shopping cart application. This repository is built **agent-first**: the
application code is not written by hand — it is generated by a team of Claude Code
sub-agents defined in [`.claude/agents/`](.claude/agents/). Each agent is committed on
its own, then invoked to build its part of the app.

## Tech Stack

| Layer     | Technology                                   |
| --------- | -------------------------------------------- |
| Frontend  | Vue 3 (Composition API) + Vite + Tailwind CSS |
| Backend   | Nuxt 3 (Nitro server routes, API only)       |
| Realtime  | Socket.io (server attached to Nitro, client in Vue) |
| Storage   | In-memory store on the backend, seeded with 10 items |

## Features

1. **Cart icon** fixed in the top-right corner with a badge showing the current number of
   items in the cart (default `0`).
2. **Landing page** listing **10 items** across **3 categories**.
3. Each item has two icon buttons: **➕ add** and **➖ remove** (to/from the cart).
4. Items are **stored on the backend**.
5. The frontend loads the item list through **CRUD REST endpoints**.
6. The cart count is updated live through **Socket.io** events.
7. **Single page** — no routing.

## Shared Contract

All agents build against this contract so the pieces fit together.

### Item model

```ts
interface Item {
  id: number
  name: string
  category: 'Electronics' | 'Clothing' | 'Books'
  price: number
  image: string // emoji or URL
}
```

### REST API (backend, base `http://localhost:3001/api`)

| Method | Path          | Purpose            |
| ------ | ------------- | ------------------ |
| GET    | `/items`      | List all items     |
| GET    | `/items/:id`  | Get one item       |
| POST   | `/items`      | Create an item     |
| PUT    | `/items/:id`  | Update an item     |
| DELETE | `/items/:id`  | Delete an item     |
| GET    | `/cart`       | Current cart state |

### Socket.io events

| Direction        | Event          | Payload                                    |
| ---------------- | -------------- | ------------------------------------------ |
| client → server  | `cart:add`     | `{ itemId: number }`                       |
| client → server  | `cart:remove`  | `{ itemId: number }`                       |
| server → clients | `cart:updated` | `{ count: number, items: Record<number, number> }` |

The server emits `cart:updated` to a client right after it connects (initial sync) and
broadcasts it to all clients after every add/remove. Removing an item that is not in the
cart is a no-op; the count never goes below `0`.

